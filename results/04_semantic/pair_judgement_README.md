# Перегляд 50 пар біля порогу (перевірка плану S4)

`pair_judgement.csv`: 50 пар семантичних ребер вихідного набору з оцінками 0,975 до 0,985 (`threshold_pairs_sample.csv`), вердикт кожної пари виставила Claude за перших 200 до 230 символів кожного з двох текстів. Довші хвости не читали, тому відмінність, яка є лише далі в тексті, могла лишитися непоміченою.

- `copy`: те саме повідомлення чи подія з тими самими фактами, відмінності лише в формулюванні, підписах чи службових словах;
- `template`: серійний формат з різними фактами (інші числа, пункти, підрозділи, дати).

Оцінювачка одна, вердикти не сліпі до оцінок схожості. Дрібні сумнівні пари (№ 28, 31, 32, 47) могли б піти в інший бік, тому частку копій слід читати з довірчим інтервалом Вілсона (рахує `scripts/s04_render_report.py`).
